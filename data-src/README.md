# data-src · 种子数据

人工核对过、体积小、需要长期留存的数据。生成物请放 `public/data/`，原件放 `cache/`。

| 文件 | 内容 | 来源 |
| --- | --- | --- |
| `hkjc_entries_index.csv` | 956 条「出賽馬匹名單」公告索引（日期/地区/标题/URL），2017-07-07 ~ 2026-11-20 | `pipeline/s1_classify.py` 生成 |
| `horse-name-seed.csv` | 63 匹日本马的中·日·英名称对照（含「前译名/民间」列） | 2026-11-02 人工整理 |
| `jockey-name-match.csv` | 483 名骑手的中日英对照与匹配状态 | 2026-11-02 人工整理 |
| `samples/20261120_MileChampionship_FinalDecl_C.docx` | 一哩冠军赛最终名单附件样本，用于验证解析器 | 香港赛马会公告附件 |

## 字段说明

**hkjc_entries_index.csv**

| 列 | 说明 |
| --- | --- |
| `date` | 公告发布日期（`YYYY-MM-DD`），非赛日 |
| `region` | 赛事所属国家/地区（按标题关键词判定，非马匹产地） |
| `title` | 原始繁体标题 |
| `url` | 公告地址（已统一 https） |

**horse-name-seed.csv**

| 列 | 说明 |
| --- | --- |
| `id` | 行号 |
| `馬名` | 日文原名（假名） |
| `欧字` | 罗马字 |
| `生年` | 出生年 |
| `现有香港馬名` | 港译 |
| `名单译名` | 港译的另一版本（公告用名） |
| `前译名/民间` | 民间通译或旧译 |
| `赛绩` | 战绩档位 |
| `状态` | `一致` / `待补` 等核对状态 |

**jockey-name-match.csv**

| 列 | 说明 |
| --- | --- |
| `项目騎手` | 本地库里的骑手写法 |
| `写法` | 汉字 / 假名 / 拉丁 |
| `出赛次数` | 出现频次 |
| `名单人名` | 港译公告里的英文名 |
| `名单译名` | 港译中文名 |
| `国籍` | 所属国家/地区 |
| `状态` | `已对上` / `名单无此人` 等 |
| `映射依据` | 匹配凭据 |

> 这两张表是 L2（民间通译）层的起点，也是校验 L1（港译）覆盖率的基准集。
